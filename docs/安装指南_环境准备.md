# 安装指南 · 环境准备

> 面向第一次在本机跑起本项目的人。按顺序做即可，全程约 15~30 分钟。
> 数据库**不用装**（SQLite 是 Python 自带的），Redis、Docker、MySQL 全都不需要。

---

## 一、需要准备的软件

### 1. 必装

| 软件 | 版本要求 | 用途 | 怎么装 |
|---|---|---|---|
| **Python** | 3.10+（推荐 3.12 / 3.13） | 后端运行时 | https://www.python.org/downloads/ ，安装时**勾选 "Add python.exe to PATH"** |
| **Node.js** | 18+（推荐 20 / 22 / 24） | 前端构建与开发服务器 | https://nodejs.org/ ，装 LTS 版即可（npm 随附） |

### 3. 编辑器推荐插件（VS Code）

- **Python**（Microsoft）——语法高亮 / 调试
- **ESLint** + **Prettier**——前端代码风格

## 二、验证环境

打开终端（PowerShell），逐条执行：

```powershell
python --version     # 期望 Python 3.10 及以上
node -v              # 期望 v18 及以上
npm -v
```

### ⚠️ 第一号坑：`python` 指向了错误的解释器

如果 `python --version` 显示的是 **3.8 / 3.7 之类的老版本**，通常是你机器上装了 Anaconda 或其它 Python，把它们加进了 PATH 并抢在前面。

**判断与解决：**

```powershell
# 列出本机所有已安装的 Python
py -0p

# 用指定版本启动器建虚拟环境，绕开 PATH 问题（推荐）
py -3.13 -m venv venv

# 想一劳永逸：把目标 Python 的安装目录及其 Scripts 目录加入「用户变量 Path」，
# 保存后必须重开所有终端 / 编辑器才生效。
```

> 关键原则：**建好虚拟环境后，一律用 `python -m pip install ...`，不要裸敲 `pip install ...`**，
> 避免装到全局或 Anaconda 环境里。

## 三、后端：安装与启动

```powershell
# 1) 进入后端目录
cd backend

# 2) 创建虚拟环境（虚拟环境 = 给项目隔离出一套干净的 Python 依赖）
python -m venv venv
# 若上面那条因版本问题失败，改用手动指定版本：
# py -3.13 -m venv venv

# 3) 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 4) 安装依赖（用国内镜像快很多）
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 5) 复制配置模板（真实 .env 不入库，请勿提交）
copy .env.example .env

# 6) 启动后端（必须在 backend 目录下，代码使用 app.xxx 绝对导入）
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

启动成功后：

- 接口文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/api/health

### 坑 2：PowerShell 禁止运行脚本

报错 `无法加载文件 ...Activate.ps1，因为在此系统上禁止运行脚本`：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force
```

### 坑 3：端口被占用

```
[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000)
```

换端口启动即可（同时要改前端代理，见下）：

```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

## 四、前端：安装与启动

另开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 **http://localhost:5173**，注册账号即可开始对话。

> 前端通过 Vite 代理把 `/api` 转发到 `http://127.0.0.1:8000`（见 `vite.config.ts`），
> 所以**不需要**额外配置 CORS。若你改了后端端口，记得同步修改该代理地址。

### 坑 4：npm 安装慢 / 失败

```powershell
# 换用国内镜像
npm config set registry https://registry.npmmirror.com
```

如果 `npm install` 反复失败，可尝试清缓存后重装：

```powershell
npm cache clean --force
npm install
```

## 五、本地大模型（Ollama，可选）

想在本地离线跑模型、或使用知识库（RAG）功能，需要装 Ollama 并拉取模型：

```bash
# 1) 启动 Ollama 服务（Windows 安装后一般已作为后台服务运行）
# 2) 拉取对话模型（默认使用 qwen3:8b）
ollama pull qwen3:8b

# 3) 知识库向量化模型（要用「知识库」功能才需要）
ollama pull bge-m3

# 4) 验证
ollama list
```

> 机器性能有限可以换更小的模型：`ollama pull qwen3:4b`，并同步修改 `.env` 的 `OLLAMA_MODEL`。

## 六、云端大模型（可选，二选一）

不想在本地跑模型，可以接入任意 **OpenAI 兼容**平台（阿里云百炼 / DeepSeek / 智谱 / OpenAI…）。
两种方式：

1. **改 `backend/.env`**：填 `CLOUD_API_KEY` / `CLOUD_BASE_URL` / `CLOUD_MODEL`，并把 `LLM_PROVIDER` 改为 `cloud`；
2. **在界面里接入**：顶栏 →「接入 / 管理云端模型」，填写 Key 与地址，**保存前会自动测连**，配错会直接告诉你原因。

> 注意：**模型名要和你所填平台的叫法一致**。同一个模型在不同平台可能不同名
> （例如百炼是 `deepseek-v3.2`，DeepSeek 官方是 `deepseek-chat`）。

## 七、一键启动（Windows）

根目录下的 `start.bat`：双击后会**同时拉起后端与前端两个窗口**，等几秒打开 http://localhost:5173 即可。
关闭时直接关掉那两个窗口。

## 八、常见问题速查

| 现象 | 原因 / 解决 |
|---|---|
| `ModuleNotFoundError: No module named 'app'` | 必须在 `backend/` 目录下启动 uvicorn |
| 回复内容为空 | 本地 Qwen3 默认开思考；确认 `.env` 里 `OLLAMA_THINK=false` |
| 云端测连报 `model_not_found` | 模型名与平台不匹配，换成该平台真实存在的名字 |
| 前端页面空白 | 后端 8000 端口没起（前端请求会 502）；先确认后端在跑 |
| `bcrypt has no attribute '__about__'` | 卸载 passlib：`python -m pip uninstall passlib` |
| 天气查不到城市 | 城市名用英文（`Beijing`），或确认天气 Key 已生效 |
