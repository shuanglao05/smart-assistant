# 智能个人助理系统 · 分享文案（精简版）

> 对外分享 / 答辩用，突出 6 个核心亮点，其余一笔带过。

---

## 项目名

**灵犀 · 智能个人助理**（Lingxi IPAS）—— 多用户 Web 版 AI 个人助理。

> 一句话：本地 / 云端大模型随便切，内置技能库定制 AI 人设，能把你的资料变成"可检索的知识库"，还能直接拿文件和图片问 AI。

---

## 五大亮点

### ① 大模型自由切换（本地 ⇄ 云端）
- 聊天顶栏一键切换：**本地 Ollama（`qwen3:8b`，离线、免费）** ⇄ **云端 OpenAI 兼容模型**（阿里云百炼 / DeepSeek / 智谱 / OpenAI…）。
- **按会话独立记忆**：不同会话可以各用各的模型，切换模型**上下文也不会断**。
- 云端模型**清单可维护**（预设 + 自定义，支持一键从平台 `/models` 拉取）；接入时**保存前真实测连**，配错立刻告诉你原因。
- **每条回答下方标注所用模型**，回看时一眼分清"这段是谁答的"。
- **深度思考开关**：一键在「秒回」与「更透彻」之间切换；**代理一键自动检测**，
  避免直连云端平台慢到每次要等一两分钟。
- 打字机流式输出，随时「停止」；答得不好可「⟳ 重新生成」；推理模型的**思考过程**可折叠查看。

### ② RAG 知识库 —— 把你的资料变成"会回答问题"的库
- 支持**多个知识库**；上传文档即**自动切分 + 向量化**（用本地 `bge-m3`，**不花钱**）。
- 聊天时**勾选知识库**，AI 就会"翻你的资料"来回答，并在回答下方**标注引用来源**（可点击查看原文）。
- **每个库可单独设检索条数（Top-K）**：规范 / 教材库调小求精准，会议记录、碎片笔记库调大求召回。
- **切片是"整句话"的**：先把正文拆成段落 / 小标题 / 句子等最小语义单元，再合并成 500 字的片段，
  相邻片段的重叠也回退到完整句子；PDF 抽取后排版换行会自动接回（一条法条不会被拆成三行）。
  实测"片段开头是半句话"的情况从 10.4% 降到 0.4%，检索命中后读起来是通的。
- **知识库关系图**：把「知识库 → 文档 → 知识片段」做成可视化图（纯 SVG 绘制，点一下片段还能看内容）。
- 例：把一本小说切卷导入后，可以让它"参考资料里的文风"写文案。

### ③ Skills 技能库 —— 给你的 AI 装"人设 / 专长"
- 技能 = 一段指令（名称 + 描述 + Prompt），**勾选即生效**：指令拼进当前会话的系统提示词，立刻改变回答风格。
- 例：启用「龙族风文案写作」后，AI 的回复自动带上冷冽克制的文风。
- 支持**新建 / 编辑 / 删除**，也能**导入 `.md` 或整个技能文件夹**（自动解析 `SKILL.md`）。

### ④ 文件与图片问答
- 输入框 📎 上传 **PDF / Word(.docx) / 文本代码**（`txt / md / markdown / csv / json / log / py / js / ts / html`，**单个最大 50MB**，可多选）
  → AI **基于文件内容**回答（PDF 用 `pypdf` 抽取文字，Word 用标准库解析、**零新增依赖**，连表格文字都能提取）。
- 上传**图片**（`png / jpg / jpeg / webp / gif / bmp`）→ 交给**多模态模型**直接看图（配合云端视觉模型效果更好）。

### ⑤ 集成日常工具
- **天气**：中文城市名即可；"北京现在天气"给实况，"北京未来三天"给逐日白天/夜间预报。
- **计算**：直接问"12 乘以 15"，AI 调用计算器返回 180（`ast` 安全解析，不用 `eval`）。
- **待办**：说"帮我记一下明天交报告"，右侧待办面板自动出现，可勾选 / 删除 / 看进度。
- **站内提醒**：说"提醒我明天上午 9 点开组会"，提醒被推进右上角通知中心（铃铛红点）。
- 另有**计时器**（倒计时 / 秒表，提示音 6 种音色 + 音量可调）、
  **日历**（备忘 + **公历 / 农历节日标注** + **放假、调休补班标注**：红色「休」/ 灰色「班」，
  数据源 timor.tech 每年自动更新）等功能页。

### ⑥ 学习 / 生活效率三件套
- **智能笔记**：按日期分组的 Markdown 笔记，编辑 / 预览切换，可让 AI **归纳要点**，支持导出 `md / txt / html / pdf / doc / json` 六种格式。
- **日程规划**：添加日程后，**开始前 5 分钟**由后端后台协程自动推送站内通知（`start_at` 用 epoch 秒存，无时区坑）。
- **课表**：节次 × 星期表格，按周次过滤（`1-16`、`1,3,5-8`、`1-16单周` 都能识别）；
  最强的是**智能导入**——粘贴教务文本、给网址、或直接**截张课表图**，AI 自动解析成课程（结果可逐条修改再入库）。
  日历与课表的格子尺寸都能拖滑杆自由调节。

## 技术栈

FastAPI · SQLite · LangChain / LangGraph · Ollama + OpenAI 兼容 API ·
React 18 + TypeScript + Vite · JWT / bcrypt。

## 快速体验

```bash
cd backend  && venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
cd frontend && npm run dev      # http://localhost:5173
```

（Windows 下也可直接双击根目录的 `start.bat` 一键启动。）
